TagpAI

A human annotation tool for AI research. Say tag-pie, like magpie.

Read a conversation one reply at a time, mark passages, tag them with a codebook, and answer a few questions about each conversation.

How it works

Each edition is a single web page that works offline. There is no login and no server behind it, and the page makes no network requests of its own. The demo keeps nothing: when you reload or close it, it starts afresh.

Status

Early demo phase: the code and a demo with made-up content. Not yet for studies.

Privacy

These pages are hosted on GitHub Pages. When a GitHub Pages site is visited, GitHub logs the visitor's IP address (see GitHub's documentation). The pages themselves make no further requests and store nothing in your browser.
