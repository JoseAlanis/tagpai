# Privacy

TagpAI is maintained by José C. García Alanis. This notice covers the
published pages (the project page and the demos at
`josealanis.github.io/tagpai/`) and TagpAI pages opened from a file.

## What the pages collect

Nothing. There are no analytics, no cookies, no tracking and no forms.

- The pages make no network requests of their own. Everything they need,
  including the app and its fonts, is inside the page, and each page's
  security policy blocks connections to any server.
- The demo stores nothing in your browser. Your marks stay in the open
  page and are gone when you reload or close it; the demo cannot save them.
- The project page contains no script at all.
- When you follow a link, the pages do not tell the other site which page
  you came from.

## Hosting

The pages are hosted on GitHub Pages. When a GitHub Pages site is visited,
GitHub logs the visitor's IP address and stores it for security purposes
(see [GitHub's documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)).
GitHub does this under its own
[privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement);
TagpAI's maintainer has no access to these logs.

The links on the pages lead to GitHub (the source code and GitHub's
documentation). Visiting GitHub is subject to GitHub's terms.

## Pages opened from a file

A TagpAI page saved to your computer and opened from there works the same
way: it makes no network requests and sends nothing anywhere. Pages built
for a study are not published here; each study explains how its files are
handled.

## Questions

Open an [issue](https://github.com/JoseAlanis/tagpai/issues) on GitHub. If
you think a page exposes or sends data it should not, please report it
privately instead, as described in [SECURITY.md](SECURITY.md).
